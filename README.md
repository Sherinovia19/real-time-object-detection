# Real-Time Object Detection using YOLOv8

A modern **computer vision web application** built with **YOLOv8 and Streamlit** that detects and classifies objects in images with a clean, professional user interface.  
This project is designed to be **easy to use, visually appealing, and deployable online**.

---

##  Features

- Upload images (JPG / PNG / JPEG)
- Real-time object detection using **YOLOv8**
- Automatic handling of RGB / RGBA / grayscale images
- Multi-object detection with confidence scores
- Color-coded bounding boxes for each detected class
- Adjustable confidence threshold
- Clean and professional UI (no emojis in title bar)
- Object statistics and analytics
- Download processed image
- Download detection results (CSV / JSON)
- Cloud deployable (Render / Hugging Face)

---

##  Tech Stack

- **Python 3.11**
- **YOLOv8 (Ultralytics)**
- **Streamlit**
- **OpenCV (Headless)**
- **PyTorch (CPU)**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **Pillow**
